# Security

Sicherheitsrelevante Probleme bitte möglichst über GitHubs private Sicherheitsmeldung (*Report a vulnerability*, sofern aktiviert) melden und nicht mit Exploitdetails als öffentlichen Issue veröffentlichen.

Signierte Releases werden mit den öffentlichen Schlüsseln unter `keys/` verifiziert. Private Schlüssel und Zugangsdaten gehören nicht ins Repository.
