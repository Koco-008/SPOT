# Beiträge zum Nachbauhandbuch

Der BMA-Stand ist eingefroren auf **SPOT OS 0.1.7 + SPOT App 0.31.1**. Künftige Änderungen an der eigentlichen Software gehören nicht in diesen Guide, sofern sie den BMA-Stand nachträglich verändern würden.

Willkommen sind Korrekturen an Text, Illustrationen, Herstellerlinks, Montagebildern, Einkaufspreisen und unabhängige Nachbau-/Erstinstallationsnachweise.

1. Erstelle ein Issue mit reproduzierbarem Problem, Hardware-Revision und genauem Arbeitsschritt.
2. Stelle eine Korrektur als Pull Request bereit; verändere keine Signaturpins, Versionen oder Software-Downloads ohne nachvollziehbare Autorisierung.
3. Für Verdrahtungsänderungen Herstellerdokumentation und möglichst Fotos eines nachweislich funktionierenden neuen Aufbaus beilegen.
4. Bei Fotos Rechte und Privatsphäre prüfen.
5. Bei Codeänderungen `python -m pytest tests -q` ausführen.

Dieses Projekt ersetzt keinen strukturierten Hardware-Sicherheitsreview. Fehlende Verifikation wird als offen dokumentiert und nicht durch eine grüne Markdown-CI „bestanden“.
